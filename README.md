# 🎨 Mi Primer Proyecto Flask - Arte

## 📌 Descripción

Este proyecto es una aplicación web básica desarrollada con Python y el framework Flask. El proyecto está enfocado en el tema del arte y presenta información sobre el arte como una forma de expresión de ideas, emociones y experiencias. 🎭🖌️

## 🎯 Propósito del proyecto

El propósito de este proyecto es conocer y comprender el arte como una forma de expresión y comunicación. También busca presentar de manera sencilla algunas de sus diferentes manifestaciones y mostrar la importancia que tiene el arte en nuestra sociedad. 🖼️✨

A través de esta aplicación se pretende que los visitantes puedan conocer un poco más sobre el mundo del arte y explorar la información presentada en sus diferentes secciones. 🎨

## 🛠️ Tecnologías utilizadas

- Python 🐍
- Flask 🌐
- HTML
- CSS
- python-dotenv

## 📂 Estructura del proyecto

- `app.py` → archivo principal de la aplicación.
- `templates/` → contiene las páginas HTML.
- `static/css/` → contiene los estilos CSS.
- `.env` → contiene las variables de configuración.
- `requirements.txt` → contiene las dependencias del proyecto.

## 📄 Páginas

- 🏠 **Inicio:** presentación del proyecto.
- 🎨 **Acerca de:** propósito e información del proyecto.
- 📩 **Contacto:** información para comunicarse sobre el proyecto.
